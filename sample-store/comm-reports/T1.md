# T1 — WeatherAPIClient 구현 보고

작성자: Implementer (sonnet)

## 개요
WeatherAPIClient는 OpenWeather API를 호출해 도시별 현재 날씨를 가져온다. ConfigLoader에서 API 키를 읽고, 실패 시 지수 백오프로 3회 재시도한다(결정 D3).

## 핵심 동작
- `fetch(city)` → OpenWeather `/weather` 엔드포인트 호출.
- ConfigLoader가 환경변수에서 `OPENWEATHER_API_KEY`를 로드해 WeatherAPIClient에 주입.
- 네트워크 오류 시 RetryPolicy(지수 백오프)로 재시도.
- 응답은 CacheStore가 보관하므로(T2) 같은 도시 재조회는 API를 다시 치지 않는다.

## 의존 관계
- WeatherAPIClient는 ConfigLoader에 의존한다.
- WeatherAPIClient의 응답은 CacheStore가 캐시한다.
- DashboardUI(T3)가 WeatherAPIClient를 호출한다.

## 검증
- 단위 테스트: 정상 응답, 404 도시, 타임아웃 재시도 케이스 통과(R1 PASS).
