# T3 — DashboardUI 구현 보고

작성자: Implementer (sonnet)

## 개요
DashboardUI는 React로 만든 대시보드 화면으로, 사용자가 입력한 도시의 날씨를 카드로 보여준다. WeatherAPIClient(T1)를 호출하고, 그 뒤에 있는 CacheStore(T2)의 캐시 이점을 그대로 받는다. API 키 등 설정은 ConfigLoader에서 읽는다(결정 D2).

## 핵심 동작
- 도시 입력 → WeatherAPIClient.fetch(city) 호출 → WeatherCard 렌더.
- 5분 내 같은 도시 재조회는 CacheStore 히트로 즉시 표시.
- 로딩/에러 상태 표시(WeatherAPIClient 재시도와 연동).

## 의존 관계
- DashboardUI는 WeatherAPIClient를 사용한다.
- DashboardUI는 ConfigLoader에서 설정을 읽는다.
- DashboardUI는 CacheStore의 캐시로 성능 이점을 얻는다.

## 검증
- 렌더 테스트는 통과하나, 접근성(a11y) 라벨 누락 발견 → R2에서 CONDITIONAL, 후속 보완 권고.
