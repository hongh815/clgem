# T2 — CacheStore 구현 보고

작성자: Implementer (sonnet)

## 개요
CacheStore는 Redis를 백엔드로 WeatherAPIClient의 응답을 도시 키별로 5분 TTL 동안 보관한다(결정 D1). 이를 통해 OpenWeather API 레이트리밋과 호출 비용을 줄인다.

## 핵심 동작
- `get(city)` / `set(city, data)` 인터페이스.
- Redis에 `weather:<city>` 키로 저장, TTL 300초.
- WeatherAPIClient는 fetch 전에 CacheStore.get을 확인하고, 미스일 때만 API를 호출한 뒤 CacheStore.set으로 채운다.

## 의존 관계
- CacheStore는 Redis에 의존한다.
- CacheStore는 WeatherAPIClient와 협력한다(캐시 미스 시 호출).
- DashboardUI(T3)는 CacheStore를 통해 빠른 재조회 이점을 얻는다.

## 검증
- 캐시 히트/미스, TTL 만료 케이스 테스트 통과(R2 PASS).
