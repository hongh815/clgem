# Cogem 4.0 Skill Governance and Scope Enforcement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use test-driven development and execute this plan task-by-task. Every code task starts with a failing regression test and ends with fresh verification evidence.

**Goal:** Enforce Skill task risk and actual write scope, support Codex-compatible Skill directories, and add deterministic Skill creation.

**Architecture:** Centralize project-path and Skill-touch predicates in `src/cogem/task_policy.py`. Add dispatch snapshot and scope comparison logic in `src/cogem/scope.py`, and keep Skill scaffolding in `src/cogem/skill_init.py`. Wire the modules into dispatch, validation, CLI, schemas, documentation, and release packaging.

**Tech Stack:** Python 3.11+ standard library, JSON, Markdown, unittest.

## Global Constraints

- Skill tasks must declare `review_level: high-risk`.
- `review_level` is required in every task JSON contract.
- Skill names are lowercase hyphenated tokens of at most 63 characters.
- Skill frontmatter contains exactly `name` and `description` as single-line scalars.
- Every Skill file is listed in `manifest.txt`.
- Scope evidence is mandatory before handoff and review.
- Commands remain non-interactive and return stable exit codes.
